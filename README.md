# No Money No Honey

Produktive Website: https://nomoneynohoney.io

Statisches HTML, CSS und JavaScript; kein Build erforderlich. Die Dateien im Repository-Hauptverzeichnis entsprechen dem Hostinger-Webverzeichnis. Stand der neuen Website: 25.10.2026.

## Gemeinsam arbeiten

Repository klonen, vor Änderungen `git pull --ff-only` ausführen und für größere Änderungen einen eigenen Branch anlegen. Änderungen committen und über einen Pull Request nach `main` übernehmen. `main` ist der Produktionsstand.

Der frühere Website-Stand bleibt in der Git-Historie und im Branch `codex/backup-before-2026-10-25` erhalten.

Kontaktformulare öffnen einen E-Mail-Entwurf. Es gibt keinen serverseitigen Formularversand. Noch offene Anbieterangaben in Impressum und Datenschutz müssen mit bestätigten Angaben vervollständigt werden.
